# Synthera - 판매실적 보고서 (Sales Report)

Synthera 판매실적 보고서 작성 및 분석을 위한 웹 애플리케이션 및 관련 프로젝트 자료입니다.

## 📁 주요 구성 파일

- **`index.html`**: 메인 판매실적 보고서 웹 애플리케이션 (`synthera_sales_report (16).html` 최신본)
- **`synthera_sales_report (16).html`**: 최신 버전 작업 파일
- **`synthera_sales_report_wizard*.html`**: 위저드 모드 UI 버전
- **보고서 및 기획서 문서**:
  - `PRD ai-pass 안.pdf`
  - `prd_ai-pass v1.pptx`
  - `2026년 3분기_판매실적.pptx`
  - `판매실적_요약본.docx`, `판매실적_취합.pptx`
  - `판매실적_SKSE_상반기실적.xlsx`, `판매실적_상세(1분기).xlsx`

## 🚀 실행 방법

- 웹 브라우저(Chrome, Edge 등)에서 `index.html`을 열어 바로 사용할 수 있습니다.
